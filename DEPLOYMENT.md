# Развёртывание Sea Level Monitor

Приложение использует SQLite. Перед запуском на Render задайте секретные переменные среды:

- `SECRET_KEY` — случайная строка не менее 32 байт;
- `ADMIN_USERNAME` и `ADMIN_PASSWORD` — имя и уникальный пароль администратора;
- `ADMIN_EMAIL` — необязательный адрес администратора;
- `SQLITE_PATH` — путь к файлу базы внутри постоянного диска;
- `BACKUP_PATH` — каталог резервных копий на постоянном диске.

Подключите постоянный диск Render и укажите его путь в `SQLITE_PATH` и `BACKUP_PATH`. Если переменные администратора не заданы, известная демонстрационная учётная запись отключается, а новые пользователи автоматически не создаются. При повторном запуске приложения пароль существующего администратора не меняется, кроме старой учётной записи из репозитория, которая заменяется паролем из окружения.

Локальный запуск после установки `requirements.txt`:

```powershell
$env:SECRET_KEY = "replace-with-a-random-secret"
$env:ADMIN_USERNAME = "admin"
$env:ADMIN_PASSWORD = "replace-with-a-unique-password"
python app.py
```

Обмен небольшими CSV-файлами:

```powershell
python scripts/csv_exchange.py export tide_gauges work/stations.csv
python scripts/csv_exchange.py import tide_gauges work/stations.csv
```

Резервное копирование через веб-интерфейс требует JWT администратора уровня 5. Каталог резервных копий не заменяет копирование на отдельное хранилище.

## Текущая погода и наблюдения за уровнем воды

После входа нажмите «Обновить реальные условия», чтобы увидеть погоду для зон из таблицы `risk_zones`; экран обновляет эти данные каждые 10 минут. Осадки и температура поступают из текущего погодного продукта Open-Meteo, то есть являются модельной оценкой в точке зоны. Нажмите «Показать радар осадков», чтобы включить последний доступный кадр RainViewer; слой автоматически обновляется каждые 10 минут. Покрытие радара зависит от региона и источников наблюдений.

Для зон, находящихся не дальше 100 км от активной приливной станции NOAA CO-OPS с официальными flood thresholds, API показывает последнее наблюдение уровня и статус относительно порога NOS Minor/Moderate/Major. Уровень преобразуется в MHHW station datum перед сравнением. Если подходящей станции нет или источник не отвечает, сайт прямо показывает отсутствие/недоступность данных. Эта система наблюдает условия, но не вычисляет вероятность затопления и не заменяет предупреждения местных служб.

Встроенные ряды измерений и часть атрибутов зон в текущей учебной БД являются демонстрационными; в интерфейсе они помечены отдельно от текущих внешних источников. Погодные API не требуют дополнительных ключей; приложение кеширует ответы на своей стороне, поэтому обновление происходит примерно раз в 10 минут.
